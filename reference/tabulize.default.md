# Prepare a default table view

Prepare a default table view

## Usage

``` r
# Default S3 method
tabulize(data, summary = TRUE, inorder = TRUE, count = FALSE, rows = NULL, ...)
```

## Arguments

- data:

  data processed with one or more functions from `tmtyro`

- summary:

  Indicates whether to prepare a summary table or the rows as they exist

- inorder:

  Indicates whether labels in the `doc_id` column should have their
  order preserved

- count:

  Determines whether frequencies will be counted for individual features

- rows:

  Chooses rows to be shown

- ...:

  optional parameters (unused)
