# tmtyro: tmtyro: Simplified Workflows for Text Mining Tyros

Work with and analyze text for simple and complex features. Adopting
tidytext principles, tmtyro abstracts processes a few levels further to
allow beginners to use and to familiarize themselves with techniques
before they understand much code.
