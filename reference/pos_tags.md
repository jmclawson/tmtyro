# Part of speech tags

Tags and descriptions for English parts of speech, designated by the
Penn Treebank Project.

## Usage

``` r
pos_tags
```

## Format

### "pos_tags"

A data frame with 36 rows and 2 columns

- tag:

  speech tag

- description:

  meaning of tag
