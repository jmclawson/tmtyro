# Prepare a table showing a document-feature matrix

Prepare a table showing a document-feature matrix

## Usage

``` r
# S3 method for class 'expanded'
tabulize(data, columns = NULL, digits = 2, ...)
```

## Arguments

- data:

  data processed with one or more functions from `tmtyro`

- columns:

  Chooses columns to be shown

- digits:

  The number of digits to show past the decimal point

- ...:

  optional parameters passed along to methods
