# Prepare a table of n-gram frequencies

Prepare a table of n-gram frequencies

## Usage

``` r
# S3 method for class 'combined_ngrams'
tabulize(.data, rows = NULL, count = TRUE, digits = 2, ...)
```

## Arguments

- .data:

  data processed with one or more functions from `tmtyro`

- rows:

  Chooses rows to be shown

- count:

  Determines whether frequencies will be counted for individual features

- digits:

  The number of digits to show past the decimal point

- ...:

  optional parameters passed along to methods
